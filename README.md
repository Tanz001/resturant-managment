# Maison Noir

Award-style immersive restaurant landing experience.

## Stack

- React + Vite (JavaScript)
- Tailwind CSS v4
- GSAP + ScrollTrigger + `@gsap/react`
- Lenis smooth scrolling
- Motion / Lucide React

## Run

```bash
cd maison-noir
npm install
npm run dev
```

Requires Node 20+ (recommended 22).
